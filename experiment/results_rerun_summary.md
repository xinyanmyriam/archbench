## 6. 关键发现

1. **标识符命名依赖（回应 R3-1）**：CI-Obfuscated 上 opus 0.246 / gpt-6-sol 0.235，而同模型 CI-Hard 分别为 0.987 / 0.911。混淆命名后准确率骤降约 70 个百分点，说明模型在组件识别中高度依赖标识符命名而非代码结构语义。
2. **模型规模效应（回应 R2-7）**：CI-Hard 上 Llama 系 maverick 0.744 → 8B 0.555（-18.9pt），Qwen 系 235B 0.703 → 8B 0.661（-4.2pt）。小模型并非普遍追平大模型，旧论文基于被空响应污染数据的“规模效应极小”结论需修正为“因模型家族而异”。
3. **L2 仓库级上下文提升 AR 召回**：opus R@5 0.600(L1) → 0.704(L2)，gpt-6-sol 0.574 → 0.688；P@5 提升较小，说明依赖图帮助模型找回更多真实边但仍引入噪声。
4. **前沿闭源模型领先**：opus 在 CI-Hard（0.968）、DP F1（0.771）、AR R@5（0.564）均居 L0 首位。
5. **解析伪影修正**：旧解析器在 CoT 长响应下系统性低估 llama 两个模型的 CI/CI-Hard，升级解析器并离线重打分后（无额外 API 调用），llama-4-maverick CI 0.588→0.994、CI-Hard 0.458→0.744；llama-3.1-8b CI 0.595→0.970。对输出裸字母的模型（如 gpt-6-sol）解析结果逐题 0 改变，验证新解析器的保守性。
